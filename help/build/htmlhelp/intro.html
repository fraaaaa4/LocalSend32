Introduction

Welcome to LocalSend32, a lightweight program made in C/Win32 to implement the LocalSend protocol in older versions of Windows, ARM-based versions of Windows, and on newer ones too, if you want a more lightweight client.

Your current version is 2.0.0, released on the 31th August 2026. Note if you’re using an older version of LocalSend32 on any device is that only 2.0 will work with LocalSend 1.18.

This guide will help you also on your first time running this app, other than instructing you on various features of the app, and troubleshooting. To check for a full table that elencates all the compatibility notes for all versions, check the readme.md in the GitHub repository.
