Settings

The Settings tab is useful if you want to change settings about LocalSend32.

General

Under general, you find all the settings about the app itself, such as:

  • saving the window position upon exiting the app; next time you open it, it’ll be shown in the same position

  • minimising the app to notification app instead of closing the app; if checked, to fully close LocalSend32 you need to right click the tray menu and then Exit

  • make the app window always on top of other windows

  • language selector: as of Version 2.0.0, the following languages are available: English, Italian, Chinese (Simplified)

  • recursively add files when selecting a folder or not; if checked, upon selecting a folder, all files in all subfolders of that folder will be added too.

Network

Under the Network tab, you can find all the settings about networking. These settings usually shouldn’t be needed to be touched by casual users.

You can set a PIN to be required for transfers; this PIN will be requested only for receiving files, not sending them.

You can change a few technical settings, such as the discovery timeout, multicast address, TLS, or the port number.

You can also change the device type and device model of your device; both of these options will be shown under the name on the other device’s LocalSend client; the device type chooser has all the typical LocalSend types of devices.

Other

In the Other tab, you can view infos about your current version of the app, as well as opening the official LocalSend website, and the GitHub repository of this project.
